файла) указаны ОТДЕЛЬНО. Экранная отрисовка временем создания HTML/PDF

## Выбор

Победитель — **H-fast** (lite-HTML первого вида 50×20, `read_only=True`,
без стилей): холодный ~40–60 мс против 1256 мс существующего HTML
на средней книге (×21), буквы — настоящий текст (читаемость выше растра),
тёплый повтор ~0,2–5 мс без перестроения.

- I-png — запасной image-вариант (без COM/PDF/браузера), но на этой машине
  дорогой: TTF-растр Arial ~6 мс/ячейка, 0,9–4,1 с холодного построения.
  Буквы читаемы (Arial, кириллица), размытие/упрощение в допуске.
- P-com — эталон оформления, не скорость: 10 с на малой книге
  (запуск Excel + экспорт + pdftoppm); согласуется с E02 (~28 с сквозной
  на клиентоподобной книге). Для первого просмотра не годится.
- HTML→PNG отсутствует (браузерного снимка нет, см. S01) — не тянем.

## Проверки стенда

- Реальный просмотр: локальный HTTP, `preview.html → 200 text/html`
  (таблица + кириллица на месте), `preview.png → 200 image/png`
  (сигнатура PNG валидна, RGB, непустой — есть тёмные пиксели текста).
- Постоянный кэш: ключ `sha1(версия|назначение|путь|mtime_ns|size|вид)`,
  повтор — без перестроения (`cacheHit`, движок 0 мс, mtime файла не меняется).
- Повтор после перезапуска (новый процесс Python, тот же кэш): HTML_HIT, PNG_HIT.
- Изменение исходника: новый ключ, перестроение (`cacheHit=false`),
  новое содержимое на месте (проверка строкой-маркером).
- Нативное открытие и общий кэш пользователя не менялись (стенд пишет
  только в свой каталог; интеграция — отдельным PR после рецензии).
- Переключение во время обработки: функции без состояния, под существующие
  epoch-защиты фронта (`waitForExcelSheetPaint`, `warmExcelWorkbook`
  сохранены как образец подключения); одновременные одинаковые запросы
  и лимиты фоновых задач — на этапе интеграции.

## Ограничения

- Только первый лист, вид 50×20, без объединений/скрытий/картинок/диаграмм;
  остальные листы — по требованию (тот же on-demand паттерн, что в лаунчере).
- Форматы чисел/процентов/дат упрощены до текстовых; legacy XLS не мерялся
  (нужен COM-конверт — только через существующий скрипт на интеграции).
- Время отрисовки в браузере не мерялось (только движок + отдача);
  на интеграции мерить через существующий `waitForExcelSheetPaint`.
- Замеры сравнительные на одной загруженной машине (параллельные агенты),
  не абсолютные нормы; повторы ×3, разброс малый, порядок не меняется.
- Клиентские книги, PDF/PNG, содержимое ячеек, пути, секреты не публикуются.
- PR не сливать. Интеграция в лаунчер — после рецензии Perplexity.
